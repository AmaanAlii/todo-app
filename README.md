# Todo App

A modern, responsive task management application
built with React, TypeScript and Tailwind CSS.

> 🚧 This project is currently under development.

## Overview

This project aims to build a clean and intuitive
task management application while following
professional frontend development practices.

The project also serves as a practical exploration
of React, TypeScript, component architecture,
testing and modern development workflows.

## Tech Stack

| Technology     | Purpose                       |
| -------------- | ----------------------------- |
| React 19       | UI development                |
| TypeScript     | Type safety                   |
| Tailwind CSS 4 | Styling                       |
| Vite           | Development and build tooling |
| ESLint         | Code quality                  |

## Getting Started

### Prerequisites

- Node.js 26.13.1
- npm 11 or compatible version

### Installation

Clone the repository:

```bash
git clone https://github.com/AmaanAlii/todo-app.git
```

Navigate to the project:

```bash
cd todo-app
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

## Available Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start development server |
| `npm run build`   | Build for production     |
| `npm run lint`    | Run ESLint               |
| `npm run preview` | Preview production build |
